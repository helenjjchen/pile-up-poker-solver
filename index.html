What counts as a scoring way?

Multiple placements can produce the same score. For example, you can swap rows and columns, move cards that do not change the hands they belong to, or make suit swaps that leave the scoring unchanged.

The solver does not list every equivalent permutation. It looks for the highest dollar value first, then keeps representative layouts only when they use meaningfully different combinations of hand types. For example, a tied total built from a straight and two pairs is a different scoring way from one built from a flush and three of a kind; rotating either board is not.

“Ways found” is the number of distinct scoring combinations found for that score—not every board that could produce it. Running Optimize again continues from the strongest layouts already found and can add a stronger score or uncover a new combination.

If the result is already certified optimal, Normal loads it immediately instead of searching again.

Pro is an anytime search, so the count can continue growing across runs.
